# Portfólio — Felipe da Conceição Silva

Página estática, sem dependências ou etapa de build.

## Rodar localmente

Execute:

    python3 -m http.server 4173

Depois, abra http://localhost:4173.

## Publicação

Os arquivos podem ser publicados diretamente em GitHub Pages, Netlify, Vercel ou qualquer hospedagem estática.

Quando o domínio público estiver definido, acrescente a URL canônica, a URL do Open Graph e um sitemap.xml com a URL final para completar a indexação.
